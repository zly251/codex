# 03_DEV_PLAN.md

## Autonomous Job Search Agent

---

# 1. 开发目标

本项目旨在构建一个自主求职代理系统。

系统能够自动完成：

* 岗位搜索
* 岗位筛选
* 岗位评分
* 简历匹配
* 自动投递
* 反馈跟踪
* 策略优化

最终目标：

提高求职效率与面试转化率。

---

# 2. 开发原则

## 2.1 MVP优先

优先实现最小可用版本。

禁止过早优化。

---

## 2.2 单用户设计

V1仅服务单用户。

不考虑多租户。

不考虑权限系统。

---

## 2.3 自动化优先

能自动完成的任务尽量自动完成。

减少人工介入。

---

# 4. Phase 1：数据层建设

目标：

建立数据存储能力。

核心工作：

* SQLite数据库
* Prisma模型
* 数据库迁移
* 基础CRUD

涉及模块：

* Resume
* Company
* Job
* Application

完成标准：

能够通过数据库管理全部核心数据。

---

# 5. Phase 2：Resume Center

目标：

建立简历管理中心。

功能：

* 导入简历
* 管理多个版本简历
* 设置默认简历
* 简历标签管理

完成标准：

系统能够根据岗位自动选择简历。

---

# 6. Phase 3：Job Crawler

目标：

建立岗位采集能力。

功能：

* 岗位抓取
* 数据清洗
* 去重
* 入库

完成标准：

系统能够持续获得岗位数据。

---

# 7. Phase 4：Scoring Engine

目标：

建立岗位评分体系。

评分维度：

* 技能匹配
* 行业匹配
* 薪资匹配
* 距离匹配
* 经验匹配

输出：

* JobScore

完成标准：

每个岗位生成可解释评分结果。

---

# 8. Phase 5：Decision Engine

目标：

自动生成投递决策。

决策类型：

AUTO_APPLY

REVIEW

IGNORE

完成标准：

所有岗位自动分类。

---

# 9. Phase 6：Apply Engine

目标：

自动执行投递。

功能：

* 自动打开岗位页面
* 自动填写信息
* 自动上传简历
* 自动提交

完成标准：

完成一次真实投递流程。

---

# 10. Phase 7：Feedback Engine

目标：

追踪投递结果。

状态：

* APPLIED
* VIEWED
* REPLIED
* INTERVIEW
* OFFER
* REJECTED

完成标准：

形成完整求职漏斗。

---

# 11. Phase 8：Strategy Engine

目标：

根据历史数据优化策略。

分析内容：

* 平台效果
* 简历效果
* 行业效果
* 距离效果

完成标准：

自动调整评分权重。

---

# 12. V1验收标准

系统能够：

1. 自动抓取岗位

2. 自动计算匹配度

3. 自动选择简历

4. 自动生成决策

5. 自动投递岗位

6. 自动记录反馈

7. 输出求职统计结果

达到以上标准即视为V1完成。
