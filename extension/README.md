# 求职助手 · 半自动（Chrome 扩展 V0）

BOSS 直聘半自动助手：扩展**只读**页面文本，交给本机 server 生成 AI 话术建议与职位含金量测算，结果显示在扩展自己的小窗里，用户手动复制后自行粘贴发送。**扩展不写页面、不模拟点击、不自动发送，封号风险低。**

## 装载步骤

1. 先启动本机 server（在项目根目录）：
   ```powershell
   node server.mjs
   ```
   server 默认监听 `http://127.0.0.1:3456`（可用环境变量 `PORT` 改）。
2. Chrome 打开 `chrome://extensions`，右上角开启「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本 `extension` 目录。
4. 打开 BOSS 直聘聊天页（`https://www.zhipin.com/...`）。**装载扩展前已打开的页面需要刷新一次**，content script 才会注入。

## 使用

1. 点浏览器工具栏里的扩展图标 → 弹出 360×600 的深色小窗（再点一次图标会聚焦已开的小窗，不会重复开）。
2. 把小窗拖到 BOSS 聊天页旁边放着即可。
3. 小窗每 **5 秒**自动轮询：读取当前活动 zhipin 标签页的可见文本 → POST 到 `http://127.0.0.1:3456/api/extension/look` → 渲染结果。
4. 每条话术建议右侧有「复制」按钮，点击即复制到剪贴板（按钮短暂显示「已复制」），粘贴到 BOSS 聊天框即可。
5. 若 AI 判定这条消息需要人工处理，小窗显示「⚠️ 这条建议人工回复」。
6. 含金量卡显示到手/可支配大字，五险一金、个税、通勤费逐行列出，每个数字旁小灰字标注来源（自报/估算）。

## 设置（小窗底部「设置」区）

| 项 | storage key | 默认 | 说明 |
|---|---|---|---|
| Server 地址 | `serverBase` | `http://127.0.0.1:3456` | server 端口不同时在这里改 |
| 轮询间隔 | `pollIntervalSec` | 5 秒 | 最小 2 秒 |
| 通勤方式 | `commuteMode` | 电动车 | 地铁/公交/电动车/自驾/步行/无 |
| 单程距离 | `oneWayKm` | 5 km | 随每次请求发给 server 算通勤费 |

改完点「保存设置」立即生效。

## 故障排查

- 状态栏显示「未找到 BOSS 页面」：切到 zhipin.com 的标签页，或刷新该页。
- 显示「连接本机 server 失败」+「重试」按钮：确认 `node server.mjs` 在跑、端口一致。
- server 地址改了不生效：轮询请求走的是内存里的最新值，保存后立即用新地址。

## 文件一览

```
manifest.json    MV3 清单
background.js    service worker：点图标开/聚焦小窗
panel.html/css/js 小窗 UI、深色样式、轮询+渲染+复制+设置
content.js       只读脚本：注入 zhipin 页，抓取可见对话文本（严格不写 DOM）
```
